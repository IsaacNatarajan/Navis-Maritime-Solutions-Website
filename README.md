# Navis Maritime Solutions website

Built with Astro. Pages are in `src/pages`, the shared header and footer in
`src/layouts` and `src/components`, styles in `public/styles/site.css`,
photos in `public/images` and videos in `public/videos`.

- `npm install` once, to download Astro
- `npm run dev` to preview at http://localhost:4321
- `npm run build` to create the final site in `dist/`
